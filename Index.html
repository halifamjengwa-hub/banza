Offline security model

Strong practical browser-only protection, with unavoidable local-device limits
AES-GCM 256-bit vaultPBKDF2-SHA-256 · 310,000 roundsUnique salt per userPer-user wrapped vault key15-minute auto-lockLocal login throttling
Important limitation: this is not server-enforced security. A person who controls the device, browser profile, or HTML file can replace the application, capture future passwords, delete storage, or bypass the interface. Use a managed device and encrypted operating-system account, restrict access to the app file, use strong unique passwords, and keep encrypted backups. For high-assurance or remote revocation, host the app behind a trusted server with centrally managed identity.
